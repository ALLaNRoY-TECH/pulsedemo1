# Pulse Gaming Arena

Open `index.html` in any modern browser to view the site. All visual assets are self-contained in `assets/`.

## Adding supplied videos

Place each `.mp4` file in `assets/`, then replace the relevant image panel with a muted, looping `<video autoplay muted loop playsinline>` element. The hero is designed to accept a full-bleed arena walkthrough video; the four zone cards and simulator panel can each accept their matching clips without changing layout or effects.

Before publishing, replace the temporary booking phone number and confirm the final pricing and tournament details.
